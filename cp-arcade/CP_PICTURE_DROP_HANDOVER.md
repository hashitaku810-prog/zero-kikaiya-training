## 2026-11-01 — Ver.1.2 手詰まり対策（公開済み）

報告: 奥さんの繰り返しプレイで、ストックが残っている状態の手詰まりが発生した。

### 原因として特定した仕様上の問題
- Ver.1.1は新作品の全ピースを1枚単位でシャッフルしてストックに格納。
- 長いゲーム（特に24/30作品）で、補充済みピースが作品ごとに分散し、次に完成可能な4枚が盤面に揃わなくなることがある。
- 落下アニメーションの Web Animations API 完了待ちにも時間上限がなかった。

### 修正
- ストックを作品単位（4枚1セット）でシャッフル・補充。組の中は4枚をランダムに並べる。6列の補充位置・落下表示は維持。
- 「🛟 手詰まり救済」ボタンを追加。確認後、未完成作品の残り全ピースを再編成するが、クリア済み作品・残ストック枚数・移動回数は変更しない。
- 救済では連結状態のみいったん解除。左上に3枚連結＋別位置の4枚目を配置し、画面の光る2箇所で1手完成が可能になる配置を事前検証する。救済は1手戻すで取り消せる。
- 落下アニメーション待ちに2400msの上限を設けて、描画完了待ちが永続しないようにした。

### 検証
- モック画像60作品を使用した実ブラウザ検証で、初期36枚、12/30作品モードのストック4枚グループ化を確認。
- 救済操作→1手で完成→補充、救済を「戻す」で完全復元、クリア済み・ストック枚数の維持を確認。
- アニメーション短縮のテスト専用ビルドで30作品すべての消去／ストック0／盤面0まで通過。
- 実画像のAndroid操作・想定外の手詰まりが残るかは今回未確認。正式COMPLETEではなく**公開済み／ユーザー確認待ち**。
- 動作問題があればゲーム画面のVer.1.2表記と、発生したモード・ストック残数・操作状況を確認する。


## 2026-11-01 — Ver.1.3 補充のゲーム性修正（Ver.1.2からの重要変更）

**ユーザーからの指摘:** Ver.1.2の「作品ごと4枚1組で補充」では、次の絵が丸ごと落ちてきて簡単すぎる。これはゲーム性を損なう変更であり、維持してはならない。

### 修正・設計原則
- **原則は1枚単位の完全シャッフル。** 画面に落ちる4枚は異なる作品が混在する。作品単位で束ねない。
- 各ターンの「ランダムな先頭4枚」を採用した場合、盤面内に完成可能な作品の4ピースがまったく存在しなくなる時に限り、ストック後部から既に盤面上に一部存在する作品の不足ピース（通常1～2枚）を先頭4枚に差し替える。ストックの総枚数や作品の枚数は変えない。
- 盤面に4ピース揃う作品がある場合、補充順には**一切介入しない**。プレイヤーの難易度を過度に下げないこと。
- 手動の「手詰まり救済」は保険として残すが、救済後のストックも1枚単位でシャッフルし、4枚のセット補充に戻らない。
- 6列ストック表現、落下列、カード交換、連結、実画像60件、スマホ画像アップロードは維持。

### 検証・制約
- 1000ゲーム×30作品＝30,000作品分の**カード出現・在庫・完成可能性シミュレーション**はPASS。
- 全4枚が同一作品となる補充: 0回。4枚とも異なる作品: 約79％。調整は基本乱数順では完成可能な作品が1件も残らない時に限定。
- 上記はカード組成のシミュレーションであり、プレイヤーの全操作をAIで解いた証明ではない。連結グループが物理的に動かしづらいケースは手動救済ボタンを利用。
- 新公開版のAndroid実機の操作・長時間プレイ再検証は未完。**公開済み／ユーザー確認待ち**。
